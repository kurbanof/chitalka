Читалка-переводчик: установка на телефон

Приложение ставится только с адреса https:// (так требует браузер). Проще всего через GitHub Pages:
1. Распакуй zip на телефоне («Файлы» → нажми на zip → «Извлечь»). На GitHub грузят сами файлы, а не zip.
2. На github.com создай репозиторий (Public). Add file → Upload files → выбери ВСЕ файлы сразу
   (в окне выбора отметь их все) → Commit changes. Файлы должны лежать в корне репозитория, не в папке.
3. Settings → Pages → Source: «Deploy from a branch», Branch: main, папка «/ (root)» → Save.
   Через 1–2 минуты вверху появится адрес вида https://имя.github.io/репозиторий/
4. Открой на телефоне в Chrome этот адрес и допиши в конце install.html:
   https://имя.github.io/репозиторий/install.html
   Эта страница проверит, что все файлы на месте, и предложит установить приложение.
   Если что-то не так, она покажет, чего не хватает, и даст скопировать отчёт.
   Вручную: меню Chrome (три точки) → «Установить приложение». На iPhone в Safari: «Поделиться» → «На экран “Домой”».
Дальше приложение работает как обычное: с иконкой, во весь экран и без интернета (кроме самого перевода).
Книги и коллекция хранятся на телефоне, в приложении.

Перевод: по умолчанию бесплатный (Google, а если он недоступен, MyMemory), ключ не нужен. Свою ИИ-модель можно подключить
в настройках перевода (значок настроек → «Движок перевода»).
