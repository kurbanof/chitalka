Читалка-переводчик: установка на телефон

Приложение устанавливается только с адреса https:// (так требует браузер). Самый простой способ:
1. Зайди на netlify.com/drop (или cloudflare pages / GitHub Pages) и перетащи в окно папку pwa целиком.
2. Откроешь выданную ссылку на телефоне в Chrome: меню (три точки) → «Установить приложение».
   На iPhone в Safari: «Поделиться» → «На экран “Домой”».
Дальше приложение работает как обычное, с иконкой, во весь экран и без интернета (кроме самого перевода).
Книги и коллекция хранятся на телефоне, в приложении.

Перевод: по умолчанию бесплатный (MyMemory), ключ не нужен. Лимит 5 000 знаков в день; если указать свой email
в настройках перевода (Aa → Движок перевода), лимит станет 50 000. Свою ИИ-модель можно подключить там же.
